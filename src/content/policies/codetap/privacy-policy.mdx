# CodeTap プライバシーポリシー

最終更新日：2026年9月30日

M33R Studio（以下「運営者」といいます。）は、Chrome拡張機能「CodeTap」（以下「本サービス」といいます。）における利用者情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

## 1. CodeTapの基本方針

CodeTapは、Webサイト上の認証コード入力欄を検出し、利用者の許可のもとGmailから対応する認証コードを検索・提示することを目的としたChrome拡張機能です。

Gmailから取得したメールデータ、検出した認証コード、およびWebページ上での認証コード入力欄の検出処理は、利用者の端末上で行われます。

Gmailから取得したメール本文または認証コードを、M33R Studioが管理するサーバーへ送信または保存することはありません。

## 2. 取り扱う情報

### Gmailから取得する情報

本サービスは、認証コードを検索するため、利用者がOAuth認証により許可したGmailアカウントについて、Gmail APIを使用して必要なメール情報を取得します。

検索処理では、メールの件名、スニペット、本文、受信日時その他認証コードの検出に必要な情報を処理する場合があります。

これらの情報は、認証コードの候補を検出し利用者に提示する目的でのみ使用します。

本サービスは、メールの送信、編集または削除を目的としてGmail APIを使用しません。

### Webページから処理する情報

本サービスは、認証コード入力欄を自動的に検出するため、Chromeによって本拡張機能のアクセスが許可されたWebページ上でコンテンツスクリプトを実行します。

この処理では、認証コード入力欄の存在や状態など、認証コード入力補助に必要なWebページ上の情報を端末内で確認します。

認証コード入力欄を検出した場合、本サービスは処理対象を管理するため、以下の情報を一時的に保持します。

- 検出したタブのURL
- 当該URLのorigin
- 認証コード入力欄を検出した時刻

これらの情報は、認証コード検索の対象となるタブや検索開始時刻を管理する目的でのみ使用します。

本サービスは、利用者の閲覧履歴をM33R Studioが管理するサーバーへ収集または保存しません。

## 3. Gmailへのアクセスが行われるタイミング

本サービスはGmailを常時監視しません。

Gmailへの検索は、主として次の場合にのみ開始されます。

- 利用者が認証コード入力欄にフォーカスした場合
- 利用者自身がCodeTapから認証コードの検索を実行した場合

認証コードの検索に必要な範囲を超えて、利用者のメールボックスを継続的に監視することを目的としてGmail APIを使用することはありません。

## 4. 利用目的

本サービスがGoogle APIその他の方法により取得または処理する情報は、次の目的に限って使用します。

- Webページ上の認証コード入力欄を検出すること
- 認証コードの候補を検索すること
- 検索対象となるタブおよび検索開始時刻を一時的に管理すること
- 認証コードを利用者に提示すること
- 利用者が選択した認証コードの入力を補助すること
- 本サービスの安全性、正常な動作および信頼性を維持すること

Gmailから取得した情報を、広告、マーケティング、ユーザープロファイリング、信用評価、AIモデルの学習その他CodeTapの認証コード入力補助とは無関係な目的には使用しません。

## 5. データの保存

### Gmailデータおよび認証コード

Gmailから取得したメール情報および検出した認証コードは、検索処理に必要な範囲で利用者の端末上の一時メモリに保持される場合があります。

これらの情報は最大5分以内に破棄され、永続ストレージには保存されません。

メール本文および認証コードを、M33R Studioが管理するサーバーへ保存することもありません。

### タブに関する一時情報

認証コード入力欄を検出したタブのURL、originおよび検出時刻は、Chromeが提供する `chrome.storage.session` を利用して一時的に保持します。

`chrome.storage.session` に保存された情報はメモリ上にのみ保持され、ディスク上の永続ストレージには保存されません。

これらの情報は、認証コード検索セッションの管理に必要な範囲でのみ使用します。

## 6. Chrome拡張機能の権限

CodeTapは、機能を提供するため、Chrome拡張機能として必要な権限を使用します。

### `storage`

認証コード入力欄を検出したタブのURL、origin、検出時刻など、認証コード検索セッションを管理するための一時的な情報を `chrome.storage.session` に保持するために使用します。

Gmail本文または認証コードを永続保存する目的では使用しません。

### `identity`

Google OAuth認証を行い、利用者自身の許可に基づいてGmail APIへアクセスするために使用します。

### `activeTab`

利用者がCodeTapを明示的に操作した場合に、現在のタブに対して必要な処理を行うために使用します。

なお、認証コード入力欄の通常の自動検出自体は `activeTab` 権限によるものではなく、manifestで定義されたコンテンツスクリプトによって行われます。

### Gmail APIへのアクセス

本サービスは、Gmail APIとの通信のため、`https://gmail.googleapis.com/*` へのアクセス権限を使用します。

### Webページ上での実行

CodeTapは、認証コード入力欄を検出できるよう、Chromeによって拡張機能のアクセスが許可されたWebページ上でコンテンツスクリプトを実行します。

この広いサイトアクセスは、さまざまなWebサービス上の認証コード入力欄を自動的に検出するというCodeTapの単一目的を実現するために使用します。

Webページから取得した情報を広告、マーケティング、閲覧履歴の作成その他認証コード入力補助と無関係な目的には使用しません。

## 7. OAuth認証情報

Googleアカウントへの認証は、GoogleおよびGoogle Chromeが提供するOAuthおよびIdentityの仕組みを利用して行われます。

運営者は、独自の認証サーバーを設けてGoogle OAuthのアクセストークンまたはリフレッシュトークンを保管しません。

利用者は、Googleアカウントの設定からCodeTapに付与したアクセス権限を取り消すことができます。

## 8. 第三者への提供

運営者は、本サービスが処理するGmail本文、認証コードその他のGoogleユーザーデータを販売しません。

また、広告事業者、データブローカーその他の第三者に対し、広告、マーケティングその他本サービスの提供と無関係な目的でこれらの情報を提供しません。

法令に基づき開示が必要となる場合その他適用法令上認められる場合を除き、Googleユーザーデータを第三者へ提供することはありません。

## 9. 人によるメールデータの閲覧

認証コードの検出は利用者の端末上で自動的に行われます。

通常のサービス運営において、M33R Studioまたはその関係者が利用者のGmail本文や認証コードを閲覧することはありません。

## 10. 広告および分析

現在、CodeTapは、Gmailから取得したデータまたは閲覧中のWebページの内容を利用した広告配信を行っていません。

また、これらの情報を独自の利用者分析または行動プロファイリングのために収集していません。

将来、クラッシュ解析や利用状況分析等、新たなデータ収集を導入する場合には、その収集を開始する前に本ポリシーおよび必要な利用者向け表示を更新し、適用される要件に従って利用者へ通知します。

Gmail APIから取得したメール本文、認証コードその他のGoogleユーザーデータを、分析目的に利用することはありません。

## 11. Google APIおよびLimited Use

CodeTapによるGoogle APIから取得した情報の利用は、適用されるGoogle API Services User Data PolicyおよびChrome Web Store User Data Policyに従います。

Google APIから取得した情報は、CodeTapの認証コード入力補助機能を提供するために必要な範囲に限定して使用します。

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## 12. セキュリティ

本サービスは、利用者情報へのアクセスを、本サービスの提供に必要な範囲に限定するよう設計します。

Gmail APIから取得したメールデータは利用者の端末上で処理し、M33R Studioが管理するサーバーへ送信しません。

Google APIとの通信にはHTTPSを使用します。

Client Secretその他、クライアント側で秘匿することが適切でない機密情報をChrome拡張機能内へ埋め込みません。

## 13. データの削除および保持期間

Gmailから一時的に取得されたメール情報および認証コードは、最大5分以内に端末上の一時メモリから破棄されます。

認証コード入力欄を検出したタブのURL、originおよび検出時刻は `chrome.storage.session` に一時的に保持され、ディスク上へ永続保存されません。

CodeTapは、Gmail本文、認証コードまたは閲覧履歴のデータベースをM33R Studioのサーバー上に保持しません。

Googleアカウントとの連携については、利用者自身がGoogleアカウントの設定からCodeTapのアクセス権限を取り消すことができます。

## 14. 未成年者の利用

CodeTapは未成年者による利用を一律に禁止していません。

法令上必要な場合には、親権者その他の法定代理人の同意を得て利用してください。

## 15. 本ポリシーの変更

本サービスの機能、取り扱う情報または外部サービスとの連携方法等を変更する場合、本ポリシーを変更することがあります。

利用者のデータの取扱いに重大な変更が生じる場合には、新たな取扱いを開始する前に、本サービスまたはM33R Studioの製品ページその他適切な方法で通知します。
